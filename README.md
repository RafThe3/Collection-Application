# Collection-Application

**Note:** As of November 2026, the custom vector collection is predicted to be replaced with a newer version of it, as well as refinements of the application itself to work with the newer version.

This project demonstrates a functioning Qt-based application using CMake that implements a custom vector collection and functioning UI to work with it, such as buttons, dropdowns, and textboxes. It successfully shows the collections ADT operations, complex sorting and searching algorithms, and basic exception handling.
